# Portfolio Widya Rahma Wulandari

Portfolio profesional untuk Administrative & Communication Professional yang memadukan presisi administrasi dengan komunikasi kreatif.

## 🌐 Live Website

Kunjungi: [https://seyyudd.github.io/widya_portfolio](https://seyyudd.github.io/widya_portfolio)

## 🚀 Fitur

- ✨ Design Modern Playful dengan aesthetic creative academy
- 🎨 Color Palette: Sage Green, Pastel Pink, dan Cream
- 📱 Fully Responsive
- 🎯 High Scannability dengan banyak white space
- 💼 Menampilkan pengalaman profesional di berbagai industri
- 🎓 Highlight kepemimpinan di organisasi kampus

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Font:** Inter & Delius (Google Fonts)
- **Deployment:** GitHub Pages

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/SeyYudd/widya_portfolio.git

# Install dependencies
npm install

# Run development server
npm run dev
```

## 🚢 Deployment

```bash
# Build dan deploy ke GitHub Pages
npm run deploy
```
